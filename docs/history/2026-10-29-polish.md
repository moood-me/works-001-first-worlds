# 2026-10-29 — Polish (`pl`)

Why: Павел: «и польский» — Polish as a further language beside the nine.

- All 46 small worlds in `worlds/`: `"pl"` in `languages`, each world's `lang/pl.json` and every scene's `lang/pl.json`
  (860 texts, 659 different). The same text in several scenes (the logbook's entries, the notebook of «Rzeczy są
  uczciwe», the signs) is translated once and the same everywhere.
- Choices: the player is «ty» — female where the Russian is («Śmierć w parku», «Rzeczy są uczciwe»), and «ty» too
  where the Russian has «вы» (the evil therapist: Polish pan/pani would need the player's gender). Russian names in
  Polish transliteration (Wiera, Sierioga, Gordiejew, Strogowa); the logbook's cat Wick is «Knot» (Polish for a wick),
  the ship «Kreczet»; bus seven is «siódemka»; signs in capitals as signs, «TWÓJ NUMER» on the queue's board.

How it was checked: moood's `check` (its `pl` branch: `pl` in `i18n/languages.json`), `node packages/check/cli.js <repo> --write`
laid the files out, the translations were written into them, then `check` on the whole repository says «all right».
From the English source, the Russian read beside it as a second view of meaning and tone. Only translations and the
`languages` lists were added; no source text, code or doc was changed.
